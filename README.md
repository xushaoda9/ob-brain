# OB Brain

OB Brain 是一款 Obsidian 桌面端知识图谱插件。它围绕当前节点展示与之直接相关的笔记，适合整理读书笔记、项目资料和长期维护的主题知识库。图谱交互参考 TheBrain，笔记阅读和编辑由 Obsidian 原生 Markdown 页签完成。

## 功能

- **围绕当前节点浏览**。父节点在上，子节点在下，手动建立的跳转节点在左，共享直接父节点的同级节点在右。一个节点可以归入多个父节点。
- **切换与编辑笔记**。点击节点后，图谱围绕它重新展开，右侧原生页签切换到对应笔记。
- **创建和连接节点**。「新建连接」支持搜索并选择已有节点，也可以按新名称创建节点，绑定已有 Markdown 笔记或创建新笔记，再建立父子或跳转关系。
- **固定主题与回看历史**。顶部一级节点栏收纳常用入口，底部默认记录最近访问的 10 个节点。
- **搜索与浏览**。按节点名称搜索，支持使用方向键和回车选择结果。图谱支持缩放和拖动平移。

## 安装

需要 **Obsidian 桌面版 1.6.6 或更新版本**。

1. 从本仓库的 GitHub Releases 下载发布包 `ob-brain.zip`。也可按下文从源码构建。
2. 将解压后的 `ob-brain` 文件夹放进目标知识库的 `.obsidian/plugins/` 目录。确认 `manifest.json`、`main.js` 和 `styles.css` 直接位于 `.obsidian/plugins/ob-brain/` 下。
3. 在 Obsidian 的「设置 → 第三方插件」中启用 **OB Brain**。若插件列表没有刷新，重启 Obsidian 后再启用。
4. 点击侧栏的 OB Brain 图标，或在命令面板运行「打开图谱」。

## 快速上手

1. 点击一级节点栏的「＋」，创建一个主题入口，例如「电影」。可以新建笔记，也可以关联知识库里已有的笔记。
2. 选中「电影」并打开「新建连接」。输入「导演」，选择已有节点或创建新节点，将它设为「电影」的子节点。
3. 点击「导演」切换图谱和右侧笔记。可以继续添加子节点，也可以把相关专题设为跳转节点。

右键已有节点可固定到一级节点栏、编辑节点或管理关系。在图谱内按 `Ctrl/Cmd + K` 可聚焦搜索框，按住 `Ctrl/Cmd` 滚动可缩放图谱。

## 数据存储

每个节点绑定一篇 Markdown 笔记，节点 ID、名称和关系等信息保存在笔记的 YAML frontmatter 中，字段名为 `ob-brain`。设置和最近访问记录由插件另行保存。图谱可导出为 JSON，其中包含节点与关系数据。导入时，目标笔记须已存在于当前知识库，已有节点的 ID 须与导入数据一致。

## 从源码构建

安装 Node.js 18 或更新版本，在项目目录执行以下命令。构建无需安装第三方 npm 依赖。

```bash
npm run check
npm test
npm run build
```

构建产物位于 `dist/ob-brain/`，可直接复制到知识库的插件目录。源码入口是 [main.js](main.js)，样式位于 [styles.css](styles.css)。更多设计说明见[功能需求文档](docs/功能需求说明.md)。
